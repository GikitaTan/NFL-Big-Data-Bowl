# 实际接球者注意力趋势分布

纳入 4465 个完成传球回合，每回合只计最终实际接球者一次。分析开球至出手前，指标为 11 名防守球员对他的注意力权重之和。

主设定下，先上升→下降→上升有 608 个，占 13.62%，不是总体最多的模式。

| 趋势 | 回合数 | 占比 |
| --- | ---: | ---: |
| 下降 → 上升 | 1140 | 25.53% |
| 上升 | 818 | 18.32% |
| 上升 → 下降 | 776 | 17.38% |
| 下降 | 609 | 13.64% |
| 上升 → 下降 → 上升 | 608 | 13.62% |
| 下降 → 上升 → 下降 | 253 | 5.67% |
| 4 段及以上 | 231 | 5.17% |
| 无显著变化 | 30 | 0.67% |

## 按观察窗口长度分组

| 时长 | 回合数 | UDU 占比 | 最常见模式 |
| --- | ---: | ---: | --- |
| 0.9–2s | 848 | 3.42% | 上升（229 个） |
| 2–3s | 2279 | 13.51% | 下降 → 上升（628 个） |
| 3–4s | 1022 | 18.88% | 下降 → 上升（250 个） |
| 4s+ | 316 | 24.68% | 上升 → 下降 → 上升（78 个） |

长回合更容易包含多次反转；4 秒及以上子组的 UDU 最多，不代表其在总体最多，也不能据此推断战术意图。

## 覆盖率与限制

原始完成传球回合 4620 个，纳入 4465 个，排除 155 个。排除原因：
- penalty_no_play: 133
- description_catch_target_disagree: 1
- missing_ball_snap: 15
- ambiguous_pass_forward: 1
- fewer_than_10_pre_release_frames: 2
- target_not_route_runner: 1
- missing_pass_forward: 2

接球者姓名来自比赛描述，与当回合进攻名单唯一匹配；另用已有接球帧标签交叉核验，存在冲突时排除。Deonte Harris/Harty 的历史姓名经 [Saints 官方资料](https://www.neworleanssaints.com/news/deonte-harris-harty-wide-receiver-new-orleans-saints-season-recap-2021)核实。

主设定为 5 帧移动平均，显著反转门槛 max(0.1, 10%×回合极差)，极值到确认反转至少 3 帧。UDU 指完整简化模式恰为上→下→上，不包括更长模式中的子串。

注意力来自几何模型，不是球员视线真值；不分析出手后到接球的飞行阶段。20 项测试通过，并核验样本唯一性、逐帧窗口和分类总数。
